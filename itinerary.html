D1　10/29（四）

台北松山 → 東京羽田 → 上野

飛抵羽田後入住上野，傍晚處理 PASS 與藥妝，不安排正式景點。

住宿：ホテルリソル上野

  1. 09:00–12:50

    中華航空 CI220 松山 → 羽田

    09:00 台北松山（TSA）起飛，12:50 抵達東京羽田（HND）。入境與領行李後再往上野。

    • 已確認

  2. 約 13:40 出發

    羽田 → 上野

    入境後搭京急空港線轉 JR 山手線或京浜東北線前往上野。一般大眾交通，JR EAST PASS 當日尚未啟用。預計 14:40～15:00 抵達飯店。

    • 自費

  3. 15:00–16:00

    辦理 JR EAST PASS 與指定席

    在 JR 上野站窗口或指定席售票機啟用／領取 JR EAST PASS 5日券（啟用日設為隔日 10/30），並預約後續はやぶさ指定席。

  4. 16:00–17:30

    上野／御徒町藥妝採買

    從飯店步行進阿美橫町，比價松本清、SUNDRUG、OS Drug 與唐吉訶德。採買清單見藥妝頁。

  5. 17:30–18:30

    晚餐

    上野站周邊或阿美橫町用餐。不預先指定餐廳，單餐以日幣 2,500 以內為原則。

D2　10/30（五）

上野 → 仙台 → 松島 → 仙台

新幹線北上仙台，中午遊松島灣並看瑞巖寺，傍晚回仙台逛街吃飯。

住宿：ダイワロイネットホテル仙台

  1. 08:43–10:15

    上野 → 仙台「はやぶさ7」

    08:43 從上野出發的東北新幹線はやぶさ7號，10:15 抵達仙台。全車指定席，出發前務必取得座位。

    • PASS
    • 指定席必訂

  2. 10:15–10:30

    仙台飯店寄放大行李

    先步行至ダイワロイネットホテル仙台（仙台站東口約 2 分鐘）寄放大型行李，再回站搭仙石線。

  3. 約 10:30–11:08

    仙台 → 松島海岸（JR 仙石線）

    約 10:30 從仙台出發的 JR 仙石線，約 11:08 抵達松島海岸站。出站即可看到灣景。

    • PASS

  4. 12:00–12:50

    松島灣遊覽船

    搭遊覽船看松島諸島。建議出發前在官網確認班次並預約。

    • 自費
    • 建議預約

  5. 12:50–13:50

    松島午餐

    碼頭與車站周邊用餐，現場選擇。避開生魚片與牛肉。

  6. 約 14:00

    瑞巖寺

    參觀國寶瑞巖寺與參道杉木。門票自費。

    • 自費

  7. 約 15:00–16:00

    返回仙台

    搭 JR 仙石線從松島海岸回到仙台。傍晚可逛仙台站 UNIQLO／PLST，再吃晚餐。

    • PASS

D3　10/31（六）

仙台 → 山寺 → 盛岡

早上逛仙台朝市，接著上山寺走走，傍晚新幹線北上盛岡。晚出晚回，節奏較鬆。

住宿：ダイワロイネットホテル盛岡駅前

  1. 08:20–09:30

    仙台朝市

    可找齋藤惣菜店ころっけや吃炸物，旁邊店家有毛豆團子。適合當早上點心或外帶。

  2. 09:40–09:50

    離開仙台飯店

    退房、帶著行李悠閒走到仙台站。

  3. 10:15–11:21

    仙台 → 山寺（JR 仙山線）

    10:15 從仙台出發的 JR 仙山線，11:21 抵達山寺站。

    • PASS

  4. 11:25–15:20

    山寺／立石寺

    出站步行至山門，再爬約 1,015 階石階到五大堂。步伐放慢，中途可休息。山上寺院區間 4–11 月 8:00 開山、16:00 前入山、17:00 前下山。

  5. 約 12:20–13:10

    山形蕎麥／山菜料理午餐

    在山寺門前或站前用餐，現場選擇。蕎麥麵與山菜最對味。

  6. 15:28–16:25

    山寺 → 北仙台（JR 仙山線）

    15:28 從山寺出發，16:25 抵達北仙台。

    • PASS

  7. 約 16:32

    北仙台 → 仙台，轉新幹線月台

    搭短程列車回仙台站，再轉東北新幹線月台。

    • PASS

  8. 17:19–17:58

    仙台 → 盛岡「はやぶさ45」

    17:19 從仙台出發的はやぶさ45號，17:58 抵達盛岡。全車指定席。

    • PASS
    • 指定席必訂

  9. 約 18:00

    盛岡入住

    ダイワロイネットホテル盛岡駅前，之後連住三晚。D4、D5 大行李留飯店。

D4　11/1（日）

盛岡市區散步 → 猊鼻溪

上午在盛岡城跡公園散步，下午只走猊鼻溪一處，避免行程過緊。

住宿：ダイワロイネットホテル盛岡駅前（連住，不退房）

  1. 07:30–08:00

    飯店附近早餐

    大行李仍寄放盛岡飯店。早餐可在車站大樓外帶，或找附近咖啡店。

  2. 08:00–09:20

    盛岡市區散步

    以盛岡城跡公園（岩手公園）與中津川周邊為主，秋天楓葉正好。

  3. 09:20–09:50

    回飯店取小行李／前往盛岡站

    只帶當日背包，大件繼續留在飯店。

  4. 10:08–10:47

    盛岡 → 一ノ關（東北新幹線）

    搭 10:08 從盛岡出發的新幹線（やまびこ52號），10:47 抵達一ノ關。

    • PASS

  5. 11:00–11:48

    一ノ關 → 猊鼻溪 Pokémon with You Train

    11:00 從一ノ關出發的 JR 大船渡線 Pokémon with You Train，11:48 抵達猊鼻溪。指定席必訂，熱門季節建議提早預約。

    • PASS
    • 指定席必訂
    • 建議預約

  6. 11:48–12:40

    猊鼻溪周邊、簡單午餐、候船

    站前或碼頭附近用餐，不預先指定餐廳。

  7. 13:00–14:30

    猊鼻溪舟下り

    13:00 班次，往返約 90 分鐘。船夫會解說岩壁並唱げいび追分。建議預約。

    • 自費
    • 建議預約

  8. 14:30–15:00

    步行返回猊鼻溪站

    從碼頭走回車站，預留十分鐘以上。

  9. 15:08–15:40

    猊鼻溪 → 一ノ關（JR 大船渡線）

    15:08 從猊鼻溪出發，15:40 抵達一ノ關。

    • PASS

  10. 16:14–16:54

    一ノ關 → 盛岡（東北新幹線）

    16:14 從一ノ關出發的やまびこ63號，16:54 抵達盛岡。下午後段以休息、晚餐為主。

    • PASS

D5　11/2（一）

住宿：ダイワロイネットホテル盛岡駅前（連住，不退房）

  1. 08:50–09:21

    盛岡 → 八戶「はやぶさ1」

    08:50 從盛岡出發的はやぶさ1號，09:21 抵達八戶。全車指定席。抵達後走到西口巴士乘車處。

    • 指定席必訂

  2. 10:00–11:44

    八戶站西口「おいらせ21號」→ 石ヶ戶

    10:00 從八戶站西口搭 JR 巴士東北「おいらせ21號」，約 11:44 在石ヶ戶下車。即使有 PASS 也必須事前預約。

    • PASS
    • 預約必要
    • 待再確認

  3. 11:44–13:15

    石ヶ戶 → 雲井の滝（健行 2.6 km）

    十和田湖休屋：午餐與湖畔散步

    約 1 小時 17 分空檔。休屋有餐廳與咖啡廳，可吃熱食或麵點，再到十和田神社或乙女像。建議上午先帶簡單輕食墊肚子。

    • 預約必要

    八戶 → 盛岡「はやぶさ64」

    18:56 從八戶出發的はやぶさ64號，19:28 抵達盛岡。備援班次 19:08 → 19:44。

    • PASS
    • 指定席必訂
